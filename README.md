# 🍺 EnterPivoBot — Telegram-бот алко-рейтингов для групповых чатов

Телеграм-бот для чатов с друзьями и коллегами, который ведет строгий учет выпитого спиртного, автоматически пересчитывает любые напитки в **водочный эквивалент** (исходя из 40% водки), еженедельно подводит итоги и определяет **Алкобарона месяца**, которого в течение всего следующего месяца саркастично троллит и унижает за алкоголизм.

---

## ✨ Основные возможности

1. **Распознавание естественного языка**:
   - Понимает живую речь: *«выпил 0.5 пива»*, *«накатил 100 водки»*, *«бахнул бокал вина»*, *«махнул рюмку коньяка»*, *«хлопнул 2 банки пива 6%»*.
   - Если пользователь не указал объём или крепость (например, *«выпил пива»* или *«выпил 200 настойки»*), бот вежливо предлагает интерактивные **Inline-кнопки** для выбора объема или процента.
2. **Математически точный водочный эквивалент**:
   - Любой напиток конвертируется по формуле:
     $$V_{\text{водки}} = V_{\text{напитка}} \times \frac{\text{Крепость}\%}{40\%}$$
   - Примеры:
     - 500 мл пива 5% $\rightarrow$ **62.5 мл** водки.
     - 150 мл вина 12.5% $\rightarrow$ **46.9 мл** водки.
     - 50 мл абсента 70% $\rightarrow$ **87.5 мл** водки.
   - **Водочный эквивалент используется исключительно для формирования топов** недели и месяца.
3. **Детальная статистика выпитого (`/mystats`)**:
   - Автоматическая классификация напитков по категориям (🍺 Пиво, 🍷 Вино, 🥃 Крепкий алкоголь, 🫧 Слабоалкогольные/коктейли, 🍸 Другое).
   - Точный физиологический учет **чистого этанола в граммах** по формуле:
     $$\text{Граммы этанола} = V_{\text{мл}} \times \frac{\text{Крепость}\%}{100\%} \times 0.789$$
   - Раздельный подсчет объема и граммов спирта по каждой категории + история последних 10 записей пользователя.
4. **Еженедельные и месячные итоги (APScheduler)**:
   - **Каждое воскресенье в 23:00** — автоматическая публикация пьедестала почета (🥇 🥈 🥉) за текущую неделю.
   - **1-го числа каждого месяца в 00:01** — официальное подведение итогов за прошлый месяц и коронация «Алко-чемпиона месяца».
5. **Механика саркастичных подколок («Доска позора»)**:
   - Победитель месяца сохраняется в базе данных.
   - В течение всего следующего месяца бот с настраиваемой вероятностью (по умолчанию 20%) язвительно отвечает на любые сообщения чемпиона в группе, напоминая ему о его диагнозе.
   - Отдельная реакция, если действующий чемпион пытается внести ещё больше алкоголя!
6. **Команды управления и меню**:
   - Команды автоматически регистрируются в меню Telegram при старте бота (кнопка «Меню» или ввод `/`).
   - `/drink 500 5 пиво` — мгновенный точный ввод без лишних слов.
   - `/cancel` или `/отмена` — удаление последней внесенной записи при ошибке (удаляется атомарно из обеих таблиц через `ON DELETE CASCADE`).
   - `/stats` или `/стата` — персональная статистика в водочном эквиваленте (сегодня, неделя, месяц, всё время).
   - `/mystats` или `/моястата` — подробная персональная статистика с разбивкой по категориям напитков, граммам чистого спирта и историей.
   - `/top` или `/топ` — текущие рейтинги чата за неделю и месяц.
   - `/winner` или `/чемпион` — действующий алкобарон прошлого месяца.
   - `/roast` или `/подкол` — тест язвительной фразы.

## 🗄 Структура базы данных

Все данные хранятся в файле SQLite (`bot_data.db`):
- `drinks` — общая таблица для быстрого расчета лидерборда (`vodka_equiv_ml`, `volume_ml`, `abv`, временные метки).
- `drinks_detail` — детальная таблица (1:1 через `drink_id` с каскадным удалением): `category`, `brand`, `pure_alcohol_g`.
- `users` — профили пользователей и их имена в чатах.
- `monthly_winners` — исторический архив чемпионов каждого месяца.
- `schema_version` — система версионирования схемы базы данных для безопасного наката миграций.

## 🚀 Установка и запуск

### 1. Клонирование репозитория и установка зависимостей
Требуется Python 3.11+.

```bash
# Клонирование
git clone https://github.com/lockdok/EnterPivoBot.git
cd EnterPivoBot

# Создание виртуального окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate

# Активация (Linux/macOS)
source .venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте `.env` и вставьте ваш токен от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
DATABASE_PATH=bot_data.db
TIMEZONE=Europe/Moscow
ROAST_PROBABILITY=0.20
AUTO_DETECT_DRINKS=false
```

`AUTO_DETECT_DRINKS` включает или отключает распознавание сообщений о напитках. По умолчанию оно выключено; команда `/drink` работает независимо от этой настройки.

### 3. Запуск бота
```bash
python -m bot.main
```

## 🔄 Безопасное обновление на сервере

Для обновления бота на сервере без риска потери данных используйте готовый скрипт:

```bash
bash scripts/update.sh
```

**Что делает скрипт:**
1. Создает автоматический бэкап текущей базы `bot_data.db` в папку `backups/` с меткой даты и времени (хранит до 15 последних копий).
2. Затягивает свежие изменения из ветки `main` (`git pull`).
3. Обновляет зависимости через `pip install`.
4. Автоматически применяет миграции схемы БД при старте (если они есть).
5. Безопасно перезапускает systemd-службу `enterpivobot` и выводит текущий статус.

## ⚙️ Добавление в Telegram-группу и настройка

1. Добавьте бота в ваш групповой чат.
2. В настройках бота через [@BotFather](https://t.me/BotFather) выключите **Group Privacy** (`/setprivacy` $\rightarrow$ `Disable`), чтобы бот мог читать естественные сообщения участников о выпитом и троллить чемпиона месяца в общем потоке.
3. Чтобы выпадающее меню команд по кнопке `/` сразу отображалось у всех участников чата, отправьте в [@BotFather](https://t.me/BotFather) команду `/setcommands`, выберите вашего бота и отправьте список:
   ```text
   drink - Записать выпитое: /drink 500 5 пиво
   stats - Личная статистика в водочном эквиваленте
   mystats - Детальная статистика по типам напитков
   top - Топ-5 чата за неделю и месяц
   winner - Действующий алкобарон месяца
   cancel - Отменить последнюю запись
   help - Как пользоваться ботом
   ```
4. Дайте боту права администратора (или обычные права на чтение и отправку сообщений).
5. Напишите `/start` или `/help` в чате.
