# 🍺 EnterPivoBot — Telegram-бот алко-рейтингов для групповых чатов

Телеграм-бот для чатов с друзьями и коллегами, который ведет строгий учет выпитого спиртного, автоматически пересчитывает любые напитки в **водочный эквивалент** (исходя из 40% водки), еженедельно подводит итоги и определяет **Алкобарона месяца**, которого в течение всего следующего месяца саркастично троллит и унижает за алкоголизм.

---

## ✨ Основные возможности

1. **Распознавание естественного языка**:
   - Понимает живую речь: *«выпил 0.5 пива»*, *«накатил 100 водки»*, *«бахнул бокал вина»*, *«махнул рюмку коньяка»*, *«хлопнул 2 банки пива 6%»*.
   - Если пользователь не указал объём или крепость (например, *«выпил пива»* или *«выпил 200 настойки»*), бот вежливо предлагает интерактивные **Inline-кнопки** для выбора объема или процента.
2. **Математически точный водочный эквивалент**:
   - Любой напиток конвертируется по формуле:
     $$V_{\text{водки}} = V_{\text{напитка}} \times \frac{\text{Крепость}\%}{40\%}$$
   - Примеры:
     - 500 мл пива 5% $\rightarrow$ **62.5 мл** водки.
     - 150 мл вина 12.5% $\rightarrow$ **46.9 мл** водки.
     - 50 мл абсента 70% $\rightarrow$ **87.5 мл** водки.
3. **Еженедельные и месячные итоги (APScheduler)**:
   - **Каждое воскресенье в 23:00** — автоматическая публикация пьедестала почета (🥇 🥈 🥉) за текущую неделю.
   - **1-го числа каждого месяца в 00:01** — официальное подведение итогов за прошлый месяц и коронация «Алко-чемпиона месяца».
4. **Механика саркастичных подколок («Доска позора»)**:
   - Победитель месяца сохраняется в базе данных.
   - В течение всего следующего месяца бот с настраиваемой вероятностью (по умолчанию 20%) язвительно отвечает на любые сообщения чемпиона в группе, напоминая ему о его диагнозе.
   - Отдельная реакция, если действующий чемпион пытается внести ещё больше алкоголя!
5. **Команды управления и отмена**:
   - `/drink 500 5 пиво` — мгновенный точный ввод без лишних слов.
   - `/cancel` или `/отмена` — удаление последней внесенной записи при ошибке.
   - `/stats` или `/стата` — персональная статистика за сегодня, неделю, месяц и всё время.
   - `/top` или `/топ` — текущие рейтинги чата за неделю и месяц.
   - `/winner` или `/чемпион` — действующий алкобарон прошлого месяца.
   - `/roast` или `/подкол` — тест язвительной фразы.

## 🚀 Установка и запуск

### 1. Клонирование репозитория и установка зависимостей
Требуется Python 3.11+.

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate

# Активация (Linux/macOS)
source .venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте `.env` и вставьте ваш токен от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
DATABASE_PATH=bot_data.db
TIMEZONE=Europe/Moscow
ROAST_PROBABILITY=0.20
```

### 3. Запуск бота
```bash
python -m bot.main
```

---

## ⚙️ Добавление в Telegram-группу

1. Добавьте бота в ваш групповой чат.
2. В настройках бота через [@BotFather](https://t.me/BotFather) выключите **Group Privacy** (`/setprivacy` $\rightarrow$ `Disable`), чтобы бот мог читать естественные сообщения участников о выпитом и троллить чемпиона месяца в общем потоке.
3. Дайте боту права администратора (или обычные права на чтение и отправку сообщений).
4. Напишите `/start` или `/help` в чате.
